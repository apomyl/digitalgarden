> [!definition] Hyperparameters
> A fixed parameter of a machine learning model (usually manually chosen by the designer). Includes things such as: no. of hidden layers, no. of neurons, learning rate, mini-batch size (for [[Gradient Descent|Stochastic Gradient Descent]]), [[Regularisation Parameter]] $\alpha$ and pruning parameter $\lambda$ (for [[Decision Trees]] and [[Support Vector Machines (SVMs)]]).
