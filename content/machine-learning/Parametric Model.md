> [!definition] Parametric Model
> Operates with a **predefined function**; making a strong initial assumption about the mapping functions from input to output.
>
> Operates using a **fixed, finite no. of parameters**.

E.g. mapped with a polynomial equations $y = ax^2 + b$ or linear equation for [[Linear Regression]]

Learning revolves around optimising the parameters to minimise error. Optimisation can happen through algorithms like [[Gradient Descent]].
