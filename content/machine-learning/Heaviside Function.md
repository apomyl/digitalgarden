> [!definition] Heaviside Function
> [[Step Functions|Step function]] that is 0 for negative inputs and 1 for positive.
> $H(x) = \begin{cases} 0 & \text{if } x < 0 \\ \frac{1}{2} & \text{if } x = 0 \\ 1 & \text{if } x > 0 \end{cases}$
