> [!definition] Cross-validation
> An evaluation method machine learning where you split data into training and testing sets, repeating with different randomised splits each time so model is generalised.
>
> Although this isn't a training technique it's used in [[Hyperparameter Tuning]] and model selection, guiding manual design choices.
