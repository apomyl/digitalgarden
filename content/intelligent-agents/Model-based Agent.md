>[!definition] Definition
>**Model-based [[Agents]]** - maintain an internal state (model of the world)
>- $b_t = U(b_{t-1}, a_{t-1}, o_t)$ then choose an action using that state $a_t= \pi(b_t)$
>- remember relevant past information
>- account for effects of previous actions
>- combine memory with new observations
