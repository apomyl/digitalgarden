> [!definition] Definition
> This is the basic action loop that defines [[Agents]], and separates them from standard automated systems by giving them "autonomy".
>
> - **Sense** - agent collects data from environment, history, etc
> - **Decide** - agent chooses next step by evaluating data
> - **Act** - agent executes chosen action
