> [!definition]
> "A communicative act is an utterance, or set of utterances (communicative act set), that we use to perform some sort of linguistic action or function in communication."

> [!tldr] Communicative Acts
>
> - Assertives - inform
> - Directives - request
> - Commissives - promise
> - Permissives - give permission
> - Prohibitives - ban some act
> - Declaratives - cause events in themselves e.g. I name this dog Rex
> - Expressives - express emotions and evaluations
